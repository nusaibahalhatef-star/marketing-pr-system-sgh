# نظام إدارة التسويق والعلاقات العامة - المستشفى السعودي الألماني (SGH)

تم تطوير هذا النظام المتكامل لإدارة قسم التسويق والعلاقات العامة في المستشفى السعودي الألماني، ليشمل إدارة المهام، المحتوى، المستخدمين، والتحليلات.

## المطور
تم التطوير بواسطة: **ايديا للإستشارات والحلول التسويقية والتقنية** (Idea for Consulting, Marketing and Technical Solutions).

## المميزات
- إدارة المستخدمين والأدوار والصلاحيات (RBAC).
- محرر محتوى متقدم مع إدارة وسائط وجدولة نشر.
- لوحة تحكم تحليلية متقدمة.
- تكامل كامل بين الواجهة الأمامية والخلفية.

## الحقوق
جميع الحقوق محفوظة لشركة **ايديا للإستشارات والحلول التسويقية والتقنية**.
